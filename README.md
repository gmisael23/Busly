# Busly — Transporte Escolar Inteligente

Aplicativo Android em Java, criado a partir do banner do 6º Workshop de Educação Continuada em TI (UNICID).

## Telas
- **Login**
- **Início:** rota do ônibus em tempo real
- **Alertas:** notificações
- **Histórico:** embarque e desembarque

Para entrar, use qualquer e-mail válido e uma senha com 6 ou mais caracteres.

## Observação
Os dados são simulados, como no protótipo do banner.
